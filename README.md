# DataCheck v0.1

Учебный проект для портфолио: веб-приложение на Python, Pandas и Streamlit для сравнения двух CSV/Excel-файлов.

## Что умеет
- загружает два файла CSV или Excel;
- показывает предварительный просмотр;
- сопоставляет строки по выбранному ключу;
- находит записи только в одном файле, различия в полях, дубли ключей и пустые ключи;
- распознаёт числа и даты и не считает расхождением разный формат их записи;
- поддерживает настраиваемые абсолютный и относительный допуски для чисел;
- игнорирует регистр и пробелы по краям в текстовых полях (правила можно отключить);
- игнорирует различия в формате дат (правило можно отключить);
- умеет не считать расхождением пару «пусто — значение» в сравниваемых полях;
- показывает вердикт, сводку качества и порядок разбора ошибок;
- экспортирует оформленный отчёт в Excel.

## Запуск на Windows (PowerShell 7)
Проверено на Windows 10, Python 3.14.3, Streamlit 1.66.1, pandas 3.1.0.

1. Откройте PowerShell 7 и перейдите в папку проекта:
   ```powershell
   cd E:\DataCheck
   ```
2. Создайте виртуальное окружение:
   ```powershell
   python -m venv .venv
   ```
3. Установите зависимости:
   ```powershell
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```
4. Запустите приложение:
   ```powershell
   .\.venv\Scripts\python.exe -m streamlit run app.py
   ```
5. Откройте http://localhost:8501, загрузите оба CSV из `sample_data`, выберите ключ `asset_id` и нажмите «Сверить файлы».

Если PowerShell блокирует запуск `Activate.ps1`, активация не нужна: команды выше используют Python из `.venv` напрямую.

## Тесты
Тесты на pytest и Streamlit AppTest проверяют запуск приложения, демо-сверку, Excel-отчёт, нормализацию чисел и дат, абсолютный и относительный допуски, правила регистра, пробелов, пустых значений и формата дат, а также сохранение ведущих нулей.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
```

Сейчас проходят 10 тестов.

## Ограничения первой версии
- При дублях ключей для сравнения берётся первая строка; дубли показываются отдельно и требуют ручной проверки.
- Для чисел задаются абсолютный и относительный допуски. Значения считаются равными, если проходит хотя бы одно правило: `|A − B| ≤ абсолютный допуск` или `|A − B| / max(|A|, |B|) × 100 ≤ относительный допуск, %`. По умолчанию: `±0.01` и `0%`.
- При нулевых допусках требуется точное равенство. По умолчанию даты сравниваются по календарному дню, а формат записи и время не учитываются. Правило можно отключить, тогда даты сравниваются как текст.
- Смешанные типы в одном поле сравниваются как текст.
- Для текстовых полей по умолчанию игнорируются регистр и пробелы в начале и конце. Оба правила можно отключить в параметрах; ключи всегда очищаются от пробелов и сравниваются с учётом регистра.
- Пустые значения в сравниваемых полях по умолчанию считаются расхождением. Правило «Игнорировать пустые значения в полях» скрывает пары «пусто — значение», но не скрывает пустые ключи.
- Не используйте конфиденциальные данные; демонстрационные CSV содержат только синтетические примеры.
- Перед использованием в рабочих процессах проверяйте результаты вручную.
